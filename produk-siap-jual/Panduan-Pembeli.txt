1. CARA INSTAL APLIKASI DI PC WINDOWS
------------------------------------------------------------------------
- Cara Otomatis (Installer):
  Klik 2x pada file "ShieldGuard-Setup-v1.0.exe", lalu klik tombol
  "INSTAL SEKARANG". Shortcut aplikasi akan otomatis muncul di Desktop.

- Cara Langsung (Portable):
  Anda juga dapat langsung mengklik 2x file "ShieldGuardFirewall.exe"
  tanpa perlu menginstal Python atau aplikasi tambahan apa pun.

- Tips Mode Admin:
  Klik kanan pada "ShieldGuardFirewall.exe" -> pilih "Run as administrator"
  jika Anda ingin mengaktifkan pemblokiran level kernel Windows Defender
  Firewall (netsh) dan sinkronisasi otomatis file Windows Hosts.

------------------------------------------------------------------------
2. CARA MEMASANG EKSTENSI DI GOOGLE CHROME & MICROSOFT EDGE
------------------------------------------------------------------------
A. Google Chrome:
   1. Buka Chrome, ketik: chrome://extensions lalu tekan Enter.
   2. Aktifkan "Developer mode" (Mode pengembang) di pojok kanan atas.
   3. Klik tombol "Load unpacked" (Muat yang belum dikemas).
   4. Pilih folder "browser-extension" yang ada di dalam paket.

B. Microsoft Edge:
   1. Buka Edge, ketik: edge://extensions lalu tekan Enter.
   2. Aktifkan "Developer mode" (Mode pengembang) di panel sebelah kiri.
   3. Klik tombol "Load unpacked" (Muat yang belum dikemas).
   4. Pilih folder "browser-extension".
